# Digital Mensches

**The Ten Commandments of Ethical Online Behavior** — a Jewish digital-ethics
program for teens. A project of URJ 6 Points Sci-Tech Academy, guided by
Rabbi Dan Medwin.

This repo serves the resource site at
**[techrabbi.org/digital-mensches](https://techrabbi.org/digital-mensches)**
via GitHub Pages: downloadable program materials plus a feedback intake
(photo/file/text/voice uploads and a Claude-powered interview) backed by the
`digital-mensches` Firebase project.
